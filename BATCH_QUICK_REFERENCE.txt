# KLSB Batch CV Generation - Quick Reference

## TL;DR - Get Started in 30 Seconds

```bash
# 1. Edit candidate data
nano candidates.csv  # or open in Excel

# 2. Run generation
python cv_batch_from_csv.py

# 3. Find generated CVs
# → uploads/cv/KLSB_BATCH_*.docx
```

## CSV Format - Copy/Paste Template

```csv
name,position,dob,nationality,marital_status,address,phone,email,linkedin,experience_summary,education,working_experience,skills,professional_training,computer_skills,professional_memberships,involvements
John Doe,Software Engineer,01-Jan-1990,Malaysian,Single,"123 St, KL",01-123456,john@email.com,linkedin.com/in/john,"5 years exp","Bachelor\nUniversity","Company X\nPosition Y\n• Task 1","• Python\n• JavaScript","Cert 1","• Python","• IEEE","• Chair 2023"
```

## Multiline Fields in CSV

Use `\n` for line breaks, quote the field:

```csv
"Line 1
Line 2
Line 3"
```

Or in Excel: `Alt+Enter` for newlines

## Output Files

Generated in: `uploads/cv/`

Naming pattern: `KLSB_BATCH_001_name.docx`

## Tips

- Use `\n` in CSV for multi-line fields
- Name/Position auto-convert to UPPERCASE
- One CSV file can generate 1000s of CVs
- Works on Windows/Mac/Linux
- Generated files ready to send/modify

## Troubleshooting

| Problem | Solution |
|---------|----------|
| No output files | Check candidates.csv exists |
| Blank fields | Verify CSV column names |
| Template error | Run `python create_template.py` |
| Slow generation | Normal - takes 1-2 sec per CV |

## Performance

- **Speed**: 1-2 seconds per CV
- **Bulk capacity**: 500 CVs in ~10 minutes
- **File size**: ~37 KB per CV
